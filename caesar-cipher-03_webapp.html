Caesar Cipher

V3.0 * ASCII 32-126 * DUAL +/-94 SHIFTS

How It Works

Every printable character shifts by a fixed number of positions across ASCII 32–126 (95 characters). Both shift keys are silently embedded into the first two characters of the output — the recipient needs no separate key. Only this app can decrypt the message.

Encrypting

  • Select ENCRYPT mode.
  • Type your message — output updates live.
  • Set shift keys with + -, type a value, or press RANDOM.
  • Send via [ COPY ], [ DOWNLOAD ], or [ SHARE ]. No key needed by the recipient.

Decrypting

  • Select DECRYPT mode.
  • Paste the ciphertext — keys are extracted automatically and shown as AUTO.
  • The decrypted message appears live in the output box.

Controls

  • RANDOM — random shift between -94 and +94.
  • CLEAR — clear the input field.
  • [ COPY ] — copy output to clipboard.
  • [ DOWNLOAD ] — save output as .txt (keys embedded in encrypt mode).
  • [ SHARE ] — share via system sheet, or copy to clipboard if unavailable.
  • Messages capped at 1000 characters.
