Caesar Cipher

V2.0 * ASCII 32-126 * +/-94 SHIFTS

How It Works

Every printable character shifts by a fixed number of positions across ASCII range 32-126 (95 characters). The same key in reverse decrypts the message.

Encrypting

  • Select ENCRYPT mode.
  • Type your message - output updates live.
  • Set shift key with + -, type a value, or press RANDOM.
  • Share the ciphertext and the key with your recipient.

Decrypting

  • Select DECRYPT mode.
  • Paste ciphertext and enter the same key used to encrypt.

Controls

  • RANDOM - random shift between -94 and +94.
  • COPY - copy output to clipboard.
  • SWAP - move output to input and flip mode.
  • CLEAR - clear the input field.
  • Messages capped at 1000 characters.
