A Field Guide to the Aetheric Cipher Engine

What is a Caesar Cipher?

A Caesar Cipher shifts each character in your message by a fixed number of positions across the printable ASCII range (characters 32–126, giving 95 possible positions). The same key applied in reverse recovers the original message perfectly.

Encrypting a Message

  • Select the Encrypt lever at the top of the apparatus.
  • Type your plaintext into the brass-rimmed chamber — up to 1,000 characters.
  • Set your Shift Key using the ▲▼ stepper, typing directly into the dial, or press ⚄ Random Shift to let the engine choose one for you.
  • Press Engage the Engine (or Enter) to produce the ciphertext output.
  • Share the ciphertext and your shift key with the recipient — both are required for decryption.

Decrypting a Message

  • Select the Decrypt lever.
  • Use the ⎘ Paste button to load ciphertext from your clipboard, or paste it manually with Ctrl+V.
  • Enter the same Shift Key used during encryption.
  • Press Engage the Engine to reveal the original message.

Useful Controls

  • ⚄ Random Shift — picks a random key between −94 and +94.
  • ⎘ Copy — copies the output to your clipboard; falls back to Ctrl+C if blocked.
  • ⇅ Use as Input — transfers the output back into the input chamber and flips the mode.
  • ✕ Clear — wipes the input chamber.
  • The brass gauge bar visualises your shift across the full ±94 range; the centre mark is zero.

Character Limit

Messages are limited to 1,000 characters. The counter turns red when 100 characters remain. Text beyond the limit is automatically truncated.
